# WeatherMap

## Description
A single-page application that takes a location (city, address or place), finds its coordinates, centers an interactive map on it, and shows the live weather in a popup.

**Live demo:** https://ruaa7.github.io/WeatherMap/

## Technologies
- HTML5, CSS3 and vanilla JavaScript (ES6+)
- Leaflet.js with OpenStreetMap (map)
- Nominatim API (geocoding)
- OpenWeatherMap Current Weather API (weather data)

## How to run
1. Get a free API key from [openweathermap.org](https://openweathermap.org/) (My API keys).
2. Open `script.js` and put your key in `WEATHER_API_KEY`:
   ```js
   const WEATHER_API_KEY = 'your_key';
   ```
3. Open the project with a local server and type a location then click Get Weather.
